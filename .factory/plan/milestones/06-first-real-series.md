title: First real series and rules review
---

Run the first real series — `marvin/subagent` against Greedy, 5 pairs under a 60,000,000-token
ceiling at concurrency 1, as Jim set it, with a second model to be named later — then review the
rules' open questions (home bonus, final-turn lunge, centre Node ping-pong, last-seen memory,
compaction, own-orientation boards, guessing check) against what the logs show. Done when a
series report exists for at least one pairing, the showcase match is selected by the rule in
brief §6.7 and renders in the viewer, and each open question is either closed with a decision or
left open with evidence. Its first task closes a gap the earlier milestones left: the CLI cannot
seat a model on a provider Pi does not know natively, so the provider entry a real run plays on
has to come out of the operator script and into a committed registry. The stats package then
grows the counters the rules' open questions are stated in — lead changes, hex flips late in the
match, Node ping-pong, re-scouts — which are also brief §6.7's showcase score, and the viewer
takes its series line from the showcase sidecar. Jim has supplied the model, the keyless
provider, the ceiling and the concurrency, so the milestone can start.
