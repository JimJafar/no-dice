---

Run the first real series between two named models against Greedy, with a cost ceiling from
Jim, then review the rules' open questions (home bonus, final-turn lunge, centre Node
ping-pong, last-seen memory, compaction, own-orientation boards, guessing check) against
what the logs show. Done when a series report exists for at least one pairing, the showcase
match is selected by the rule in brief §6.7 and renders in the viewer, and each open
question is either closed with a decision or left open with evidence. This milestone cannot
start until Jim supplies model IDs, API keys and a cost ceiling; the planning task for it
asks for them.
